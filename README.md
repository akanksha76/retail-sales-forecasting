# Retail Sales Analysis and AI Forecasting

## Project Overview
This project analyzes retail sales data to identify business trends, evaluate key performance indicators (KPIs), and forecast future sales using time-series forecasting techniques.

## Objectives
- Analyze retail sales and revenue trends.
- Identify top-performing product categories.
- Evaluate sales, discounts, and business performance.
- Compare forecasting models and generate future sales predictions.
- Build an interactive Power BI dashboard for business insights.

## Tools and Technologies
- **Python:** Data cleaning, analysis, and forecasting
- **Pandas and NumPy:** Data manipulation
- **Matplotlib:** Data visualization
- **Holt-Winters:** Time-series forecasting
- **Random Forest:** Forecasting model comparison
- **Power BI:** Interactive dashboard development
- **Jupyter Notebook:** Analysis and experimentation
- **Excel and CSV:** Data storage and reporting

## Project Files
- `Retail_Analytics_Major_Project.ipynb` — Analysis and forecasting notebook
- `RETAIL SALES ANALYTICS DASHBOARD.pbix` — Power BI dashboard
- `Retail_Analytics_Project_Results.xlsx` — Project results
- `Retail_Sales_Data.xlsx` — Retail sales dataset
- `forecast_model_comparison.csv` — Forecasting model comparison
- `30_day_sales_forecast.csv` — 30-day forecast output

## Key Findings
- Electronics was the highest-revenue product category in the analysis.
- Holt-Winters achieved a WAPE of approximately 9.86%.
- Random Forest achieved a WAPE of approximately 10.19%.
- Holt-Winters performed best among the evaluated forecasting models.

## How to Explore
1. Open the Jupyter Notebook to review the analysis and forecasting workflow.
2. Open the Power BI file using Microsoft Power BI Desktop.
3. Review the model comparison and forecast output files.
